# ギリギリ株式会社

危険ラインの直前でゲージを止める、1プレイ1〜2分のワンタップ・ブラウザゲームです。

## 遊び方

1. 「出社する」を押す
2. ゲージが右へ進む
3. 赤い危険ラインを越える前に `STOP!`
4. ラインに近いほど高得点
5. 全10ラウンドの合計点で査定

PCでは Space / Enter でもSTOPできます。

## 特殊ラウンド

- 急加速: 後半でゲージが加速
- 差し戻し: 一度逆走してから再提出
- 画面共有: 危険ライン手前で一瞬見えなくなる
- 稟議迷路: ダミーの危険ラインが出現
- 最終査定: 暗転と急加速の複合ラウンド

## 技術

- Vanilla HTML / CSS / JavaScript
- ビルド不要
- `localStorage` にハイスコア保存
- モバイルファースト
- `prefers-reduced-motion` 対応

`index.html` をそのまま開くか、GitHub Pagesなどの静的ホスティングに配置して遊べます。
