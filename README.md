# ギリギリ株式会社

危険ラインの直前でゲージを止める、ワンボタンのブラウザゲームです。  
1プレイはおよそ 1〜2 分。説明は 3 秒、リトライしたくなるテンポを目指しています。

## 遊び方

1. `出勤する` を押す（PC なら Space / Enter でも可）
2. ゲージが SAFE 側から危険ラインへ進む
3. 巨大な `STOP!` を、危険ラインの直前で押す
4. ラインに近いほど高得点。越えたらそのラウンドは `OUT`
5. 即ゲームオーバーにはせず、10 ラウンドの合計点で競う

判定は `PERFECT` / `GREAT` / `NICE` / `SAFE` / `OUT`。  
連続成功でコンボ倍率が上がります。

## 特殊ラウンド

仕事っぽい理不尽が混ざります。

| 種類 | 内容 |
| --- | --- |
| 急加速 | 後半だけ突然速くなる |
| 逆走 | 一度戻ってから再び進む |
| 暗転 | 危険ライン手前でゲージが一瞬見えなくなる |
| フェイク | 破線の「下書き」ラインが出る。本物は金色の「本番」 |

## 起動方法

ビルド不要です。静的ファイルだけなので、次のいずれかで遊べます。

- `index.html` をブラウザで開く
- ローカルで静的サーバを立てる

```bash
python3 -m http.server 8080
```

GitHub Pages など、静的ホスティングにこのリポジトリを置くとそのまま公開できます。

## ファイル

- `index.html` … 画面構造
- `styles.css` … 筐体風 UI とモバイル優先レイアウト
- `game.js` … ゲージ制御・判定・特殊ラウンド・保存
- `README.md` … このファイル

ハイスコアはブラウザの `localStorage`（キー: `girigiri-inc-highscore`）に保存します。

## 操作・対応

- 基本操作は `STOP!` ボタンのみ。Space / Enter でも同じ
- スマホは 390px 前後（iPhone）を優先。PC では中央の筐体レイアウト
- 横スクロールなし、タップ領域は大きく、連打で状態が壊れないように入力をロック
- `prefers-reduced-motion` ではシェイク等の演出を抑える
- 外部画像なし（CSS のみ）
